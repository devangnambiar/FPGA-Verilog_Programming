# FPGA Verilog Roadmap

This repository documents my journey from learning the fundamentals of Verilog HDL to designing complex FPGA-based digital systems. The goal of this project is to build a strong foundation in digital design, RTL development, simulation, verification, FPGA implementation, and hardware architecture.

The roadmap begins with fundamental combinational and sequential logic modules such as adders, multiplexers, decoders, encoders, counters, registers, and finite state machines. Each module is implemented in Verilog, verified through custom testbenches, simulated using Icarus Verilog, and analyzed using GTKWave.

As the project progresses, more advanced topics such as FPGA design flows, memory interfaces, communication protocols, and hardware optimization techniques will be explored. The long-term objective is to apply these skills to the development of larger FPGA projects, culminating in the implementation of a NAND Flash Controller and other industry-relevant digital systems.

This repository serves as both a learning log and a portfolio of Verilog and FPGA development projects, showcasing the progression from basic digital logic to complex hardware systems.
